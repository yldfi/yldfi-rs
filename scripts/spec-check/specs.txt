# Weekly API spec check: the published spec of each upstream API a crate wraps.
#
# Format:  provider | crate | openapi|mintlify|readme|graphql | spec URL
#   - openapi: an OpenAPI 3 or Swagger 2 document (JSON or YAML), fetched with GET
#   - mintlify: Mintlify docs with one spec per endpoint page; the URL is the
#     docs base, pages are listed from its llms.txt
#   - readme: ReadMe docs that embed a spec in each /reference/<page>.md;
#     the URL is the docs base, pages are listed from its llms.txt
#   - graphql: a GraphQL endpoint, queried with an introspection POST
#   - ${VAR} in a URL is read from the environment; the spec is skipped when
#     it is unset and the value is redacted from output.
#   - Prefer the provider's own endpoint or its repo's main branch over a
#     versioned docs URL. The crate column is the directory under crates/ whose
#     path literals mark which operations are "used by crate". The report's
#     "paths not in the spec" list is a heuristic: a crate that also calls a host
#     without a spec (alcmy's gas manager) always shows those paths.
#
# No public spec (covered only by the live check in scripts/api-check/):
# Solodit, Chainlink Data Streams REST, OpenOcean. The live Hermes server
# doesn't serve its spec, so Pyth uses the copy committed for its JS client.
